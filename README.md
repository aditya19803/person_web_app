# person_web_app
# Node.js + MongoDB RESTful API (Person CRUD)

A simple CRUD web app using Node.js, Express, MongoDB, and EJS templates.

## Features
- Create, Read, Update, Delete people
- Fields: Name, Age, Gender, Mobile

## Setup
1. Clone repo
2. Run `npm install`
3. Set `.env` with Mongo URI
4. Run `npm start`
